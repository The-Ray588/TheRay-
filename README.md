**Не просто сайт-визитка.** Это интерактивная вселенная, где каждая деталь — от гравитации звёзд до звуков клика — создаёт ощущение магии.  
Полноэкранная навигация, 3D-эффекты и плавность 60 FPS.

## 🛠 Технологический стек

<div align="center">

| Технология | Роль в проекте |
| :--- | :--- |
| **HTML5** | Семантическая разметка, доступность |
| **CSS3** | 3D-трансформации, `backdrop-filter`, градиенты, анимации |
| **JavaScript** | Canvas-галактика, физика, Web Audio API, Tilt-эффект |
| **Google Fonts** | Шрифты `Comfortaa` и `Caveat` |

</div>

> ⚡ **Ноль зависимостей.** Никаких React, Vue или тяжелых библиотек. Только чистый код, оптимизированный до 60 FPS.

## 📦 Как запустить

```bash
# 1. Клонируй репозиторий
git clone https://github.com/TheRayDev/ray-bio.git

# 2. Перейди в папку
cd ray-bio

# 3. Открой index.html в браузере
```

(Или просто скачай архив и открой index.html).

❓ FAQ

<details>
<summary><b>🎨 Можно ли использовать этот код в своих проектах?</b></summary>
<br>
Да! Проект распространяется под лицензией MIT. Ты можешь брать код, менять его, использовать в личных и коммерческих целях. Главное — сохранить упоминание авторов.
</details>

<details>
<summary><b>📱 Сайт работает на телефоне?</b></summary>
<br>
Да, вёрстка адаптивная. Кастомный курсор, спотлайт и тяжелые 3D-эффекты на мобильных отключаются автоматически, чтобы сайт летал.
</details>

<details>
<summary><b>⚡ Почему нет React/Vue?</b></summary>
<br>
Потому что для такого проекта они не нужны. Чистый HTML/CSS/JS с оптимизацией до 60 FPS работает быстрее и не тянет за собой кучу зависимостей.
</details>
