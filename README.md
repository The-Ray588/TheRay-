## 🚀 О проекте

Это не просто сайт-визитка. Это **путешествие** от холодного космоса к тёплому личному дневнику. 
Каждая деталь продумана: от физики кулона до шлейфа за курсором.

<div align="center">

| 🌠 **3D-кулон** | 🌌 **Живой космос** | 🖱️ **Кастомный курсор** |
| :---: | :---: | :---: |
| Реагирует на мышь, физика маятника | Мерцающие звёзды, кометы, искры | Оранжевая искра с шлейфом |
| 📜 **Параллакс** | 🧭 **Боковое меню** | 📓 **Блокнот** |
| Смена цвета от заката к ночи | Быстрая навигация по секциям | «Мысли Рэйя» с мемами |

</div>

## 🛠 Технологический стек

<div align="center">

| Технология | Роль в проекте |
| :--- | :--- |
| **HTML5** | Семантическая разметка, доступность |
| **CSS3** | Анимации, `backdrop-filter`, градиенты, 3D-трансформации |
| **JavaScript** | Физика кулона, генерация звёзд, кастомный курсор |
| **Google Fonts** | Шрифты `Comfortaa` и `Caveat` |

</div>

> ⚡ **Ноль зависимостей.** Никаких библиотек, фреймворков или сборщиков. Только чистый код, который грузится мгновенно.

## 📦 Как запустить

```bash
# 1. Клонируй репозиторий
git clone https://github.com/ТвойНик/ray-bio.git

# 2. Перейди в папку
cd ray-bio

# 3. Открой index.html в браузере
```

(Или просто скачай архив и открой index.html).
